# HealthMate

## Project Overview

HealthMate is a personal health and wellness tracking mobile application designed to help users record, manage and review their daily health activities.

This application is being developed as part of the CI6330 Mobile Application Development coursework at Kingston University.

## Planned Application Features

- Add daily health records.
- View previous health records.
- Update and delete existing records.
- Search and filter records by date.
- View daily health activity summaries.
- Track water intake progress.
- View seven-day health activity summaries.
- Store health records locally using SQLite.

## Technologies

- Java
- Native Android
- Android Studio
- Android SDK
- SQLite
- MVVM Architecture
- Git and GitHub
